# User Stories for HomeFinder App

> Written from the perspective of our two core users: Renters and Landlords.
> Format: "As a [user type], I want to [action] so that [benefit]."
> Drafted by: Adejumo Adeyemi — PM
> Sprint: Sprint 2 — Define & User Stories
> Date: April 2026



## Authentication Stories

| # | User Story | Priority |
|---|---|---|
| US-01 | As a new user, I want to select whether I am a renter or a landlord so that the app shows me the right experience for my needs. | M |
| US-02 | As a renter, I want to sign up using my email and password so that I can create a secure personal account and access the platform. | M |
| US-03 | As a landlord, I want to sign up and create an account so that I can access the platform and list my properties for rent. | M |
| US-04 | As a registered user, I want to log in with my email and password so that I can securely access my account at any time. | M |
| US-05 | As a registered user, I want to reset my password via email so that I can regain access to my account if I forget my password. | S |



## Renter Stories

| # | User Story | Priority |
|---|---|---|
| US-06 | As a renter, I want to create a profile with my name, photo, contact details and a short bio so that landlords can know who is requesting to rent their property. | M |
| US-07 | As a renter, I want to see all available property listings on my homepage so that I can browse a wide variety of options in one place. | M |
| US-08 | As a renter, I want to search for properties by city or location so that I can quickly find listings relevant to where I want to live. | M |
| US-09 | As a renter, I want to filter listings by location, price range, home type and date posted so that I can narrow down my search and find the most relevant options faster. | M |
| US-10 | As a renter, I want to view full property details including photos, price, description, amenities and landlord information so that I can make an informed decision before requesting an inspection. | M |
| US-11 | As a renter, I want to connect directly with a landlord or request a property inspection so that I can communicate without going through an agent or middleman. | M |
| US-12 | As a renter, I want to save and shortlist properties I am interested in so that I can easily revisit and compare them later without searching again. | S |
| US-13 | As a renter, I want to see property recommendations similar to what I have searched or viewed so that I can discover relevant listings without starting a new search every time. | S |
| US-14 | As a renter, I want to update my password and profile image in settings so that I can keep my account information current and secure. | S |



## Landlord Stories

| # | User Story | Priority |
|---|---|---|
| US-15 | As a landlord, I want to create a profile with my name, bio and contact details so that renters can know who they are renting from and trust who they are dealing with. | M |
| US-16 | As a landlord, I want to post a property listing with photos, videos, price, location, home type, amenities and a full description so that renters have all the information they need to decide if the property suits them. | M |
| US-17 | As a landlord, I want to see all my listed properties displayed on my profile catalog so that I can manage and keep track of everything I have listed. | M |
| US-18 | As a landlord, I want to view all inspection and rent requests from renters so that I can stay organised and respond to interested renters promptly. | M |
| US-19 | As a landlord, I want to accept or decline inspection requests based on my availability and the renter's profile so that I have full control over who inspects my property. | M |
| US-20 | As a landlord, I want a verified badge displayed on my profile and listings so that renters can trust that I am a legitimate property owner. | S |
| US-21 | As a landlord, I want to edit, pause or delete my listings so that I can keep my catalog accurate and up to date. | S |

## Definition of Done

A user story is considered complete when:
- [ ] Feature is built and functional
- [ ] Tested on mobile (Android and iOS)
- [ ] Reviewed and approved by Lead PM
- [ ] Ticket moved to Done on Jira
