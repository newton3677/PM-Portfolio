---

## MVP Definition

The **Minimum Viable Product (MVP)** of HomeFinder includes all **Must Have (M)** features.

With only the Must Haves, a renter can:
1. Create a profile and set their location
2. Browse listed homes on the feed
3. Search and filter by location, budget and home type
4. View full property details with images
5. Connect directly with a landlord or request an inspection

And a landlord can:
1. Create a verified profile
2. Post a listing with images and full description
3. View and manage inspection requests from renters
4. Accept or decline requests

> This is a complete, functional product that solves the core problem without any extras.

---

## What We Are NOT Building in v1

- In-app payment or rent collection
- Agent accounts or agent-facing features
- Chat or messaging system (using direct contact for now)
- Map view of listings
- Review or rating system
